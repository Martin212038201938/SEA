# Wissensbasis des SEA-Cockpits

Alle `.md`-Dateien in diesem Ordner werden dem Sprachmodell bei Reports (Auszug, max. ca. 12.000 Zeichen)
und im Chat über das Werkzeug `get_knowledge` zur Verfügung gestellt.

Was hierher gehört: frühere Analysen und Entscheidungen, Hypothesen, Rahmenbedingungen, Negativlisten,
Landingpage-Stand, alles, was das Modell wissen soll, bevor es Vorschläge macht.

Was nicht hierher gehört: Zugangsdaten, Kundendaten mit Namen, rohe Exporte (die liegen in der Datenbank).

Neue Datei anlegen, committen, deployen. Dateinamen mit Datum beginnen (`2026-10-…`), damit die Reihenfolge stimmt.
